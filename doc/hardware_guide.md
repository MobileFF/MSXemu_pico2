# ハードウェア・ガイド

このガイドでは、MSX1 エミュレータ（Raspberry Pi Pico 2 + MicroPython）を構築するために必要なハードウェアコンポーネントと配線について説明します。

## 部品表 (BOM)

- **マイクロコントローラ**: Raspberry Pi Pico 2 (RP2350)。USBホスト機能とパフォーマンスの両面から必須です（RP2040 Pico無印は非対応）。
- **ディスプレイ**: 以下のいずれか（`config.txt` の `lcd=` で実行時に切り替え可能。配線・初期化シーケンスは共通）
  - **ST7796 480×320 TFT LCD**（通称 MSP4021）— デフォルト。MSXの256×192画面を中央に等倍表示。
  - **ILI9341 320×240 TFT LCD**（通称 MSP2402）
- **ストレージ**: Micro SD カードモジュール（SPI インターフェース）。BIOS/カートリッジROM・設定ファイル・セーブデータを格納。
- **USB ホスト**: USB OTG アダプタ（Micro-USB オス — USB-A メス）キーボード接続用。Pico 2 のネイティブ USB ポートを使用（USB CDC は無効化されているため、シリアルコンソールは別途 UART が必要）。
- **音声出力**: パッシブ圧電ブザー、または RC ローパスフィルタ経由でイヤフォン/スピーカーへ（後述）。
- **ジョイスティック**（任意）: ATARI/MSX 標準 9 ピンジョイスティックポート相当。GPIO直結。
- **電源**: USB 電源 (5V)。
- **その他**: ブレッドボード、ジャンパーワイヤー。

## ピンアサイン

コンソール UART と USB を除き、LCD・SD カードは同じ SPI バス（SPI1）を共有します。

### 1. LCD ディスプレイ (SPI1)

| LCD ピン | Pico ピン | 機能 | 備考 |
| :--- | :--- | :--- | :--- |
| VCC | 3.3V | 電源 | |
| GND | GND | グランド | |
| CS | GP9 | チップセレクト | |
| DC / RS | GP8 | データ/コマンド | |
| RST | GP7 | リセット | |
| SDI (MOSI) | GP11 | SPI1 TX | SDカードと共有 |
| SCK | GP10 | SPI1 SCK | SDカードと共有 |
| SDO (MISO) | GP12 | SPI1 RX | SDカードと共有（未使用でも配線推奨） |
| LED (BL) | GP22 | バックライト | |

SPI ボーレートは 62.5MHz（`main.py` の `SPI_BAUD`）。この基板配線で確認できた実用上限であり、125MHz では表示が乱れることを実機で確認済みです。

`config.txt` の `lcd=ST7796` または `lcd=ILI9341` でパネルサイズを切り替えます（省略時は ST7796=480×320）。MSXのネイティブ解像度 256×192 はスケーリングせずパネル中央に等倍表示されます（拡大表示は転送量が増え体感速度が大きく低下するため採用していません）。

`config.txt` の `rotate=180` を指定すると、LCDパネルを上下反転（180度回転）して表示します（上下逆さ取り付け対策）。

### 2. SD カードモジュール (SPI1)

| SD ピン | Pico ピン | 機能 | 備考 |
| :--- | :--- | :--- | :--- |
| VCC | 3.3V | 電源 | |
| GND | GND | グランド | |
| CS | GP15 | チップセレクト | |
| MOSI | GP11 | SPI1 TX | LCDと共有 |
| SCK | GP10 | SPI1 SCK | LCDと共有 |
| MISO | GP12 | SPI1 RX | LCDと共有。プルアップ必須（後述） |

> **重要**: SPI1_RX (GP12) は SD の MISO も兼ねます。SDカードが CS 非選択時に MISO をハイインピーダンスにするため、**プルアップ抵抗（内部プルアップで可）が無いとフローティングして 0x00 に読めてしまい、SDカード初期化コマンドが誤って成功したように見えてタイムアウトする**問題が起きます。ファームウェア側で `gpio_pull_up(12)` を自動設定していますが、外付けプルアップ（10kΩ程度）を追加しても構いません。

Pico内蔵フラッシュ（QSPI、SPI1とは別系統）にはメガロム（バンク切替の大容量カートリッジROM）用の一時キャッシュ領域として約3MBの空き容量があります。SDカードからの読み込みはゲーム選択時の一度のみで、プレイ中はアクセスしません（詳細は `usage_guide.md` を参照）。

### 3. UART コンソール

| 機能 | Pico ピン | 備考 |
| :--- | :--- | :--- |
| UART0 TX | GP0 | デバッグ / REPL 出力 |
| UART0 RX | GP1 | REPL 入力 |

ネイティブ USB CDC はこのファームウェアで無効化されている（ネイティブ USB ポートは USB ホスト専用のため）ので、`mpremote` 等での開発時デバッグ接続には別途 USB-UART 変換アダプタ（FTDI等）をこの UART0 に接続する必要があります。

### 4. 音声出力 (PWM)

| 機能 | Pico ピン | 備考 |
| :--- | :--- | :--- |
| PSGオーディオ出力 | **GP14** | PWM出力（10bit、約234kHzキャリア） |

#### パッシブ圧電ブザーへの直結（簡易）

GP14 を抵抗（100Ω程度）経由でブザーに接続するだけで音は出ますが、PWMの生の高周波成分がブザーの共振板を直接叩くため、やや耳障りな音質になります。`config.txt` の `volume=`（デフォルト256、0-256）で音量を、`audio_filter=`（デフォルト0、0-8）でデジタルローパスフィルタの強さを調整できます（実行時メニューの Audio Settings からも調整可能）。

#### イヤフォン/スピーカー出力（推奨、要ハードウェア追加）

PWM出力をそのままイヤフォン等に繋ぐと、DC成分・搬送波ノイズ・過大音量の問題があります。以下のような簡易 RC ローパスフィルタ + DCカット回路の追加を推奨します。

```
GP14 ──[R1: 1kΩ]──┬──[R2: 1kΩ]──┬─── (DCカット) ──[C2: 10µF]── イヤフォン端子(TIP/RING共通)
                   │             │
                 [C1: 4.7nF]   [C1b: 4.7nF]
                   │             │
                  GND           GND
                                              イヤフォン端子(GND) ─── GND
```

- R1+C1、R2+C1b の2段RCローパス（各段カットオフ約34kHz）で234kHzの搬送波を十分減衰
- C2（10µF程度）でDC成分を遮断してからイヤフォンへ
- TIP/RINGはそれぞれ独立抵抗（例: 220Ω）を介して同じ信号ノードに接続すればモノラルをL/R両方に出力可能

### 5. ジョイスティック（任意）

ATARI/MSX 標準 9 ピンジョイスティックポート相当の信号を、直結方式（GPIO内蔵PULL_UP入力、アクティブ LOW）で接続します。JOY1（1系統）のみ対応。

| 信号 | Pico ピン | 備考 |
| :--- | :--- | :--- |
| UP | GP18 | |
| DOWN | GP19 | |
| LEFT | GP20 | |
| RIGHT | GP21 | |
| TRIGGER A | GP26 | |
| TRIGGER B | GP27 | |

各ピンはボタン/スイッチでGNDへ短絡すると「押下」として認識されます（アクティブLOW）。ソフトウェア側は実機のMSXと同じ経路（PSG＝AY-3-8910のI/OポートA/B、レジスタ14/15）でこの状態をZ80から読み取れるようにエミュレートしているため、実機用ゲームソフトのジョイスティック入力ルーチンがそのまま動作します。

未配線でも問題ありません（内蔵プルアップにより常にHIGH＝未入力として扱われます）。

### 6. USB キーボード

- USB キーボードを USB OTG アダプタ経由で Pico 2 のネイティブ Micro-USB ポートに接続します（GP24/25、TinyUSB ホストスタック使用）。
- USB ホスト初期化時に `clk_sys` が 240MHz に強制設定されます（USB フルスピードのタイミング精度確保のため。エミュレーション速度への影響は軽微）。

## 配線上の注意点

- **SPI 共有**: LCD・SD の CS（チップセレクト）ピンは独立している必要があります。起動時にすべての CS ピンを HIGH に設定してから初期化してください（ファームウェアが自動的に行います）。
- **電力消費**: LCD のバックライトはかなりの電流を消費します。Pico が再起動したり画面がちらついたりする場合は、外部 3.3V/5V レギュレータからの給電を検討してください。
- **ロジックレベル**: すべてのピンは 3.3V ロジックです。5V の信号を Pico のピンに直接接続しないでください。
- **LCDとSDが同じSPIバスを共有しているため、片方の配線不良がもう片方の動作にも影響することがあります。** 画面が真っ暗でSDカードも認識しない場合は、まずプレーンなMicroPython（`msx`モジュール不使用）でSDマウントのみ試し、配線側の問題かソフト側の問題かを切り分けてください。
