# 実行時メニュー・ホットキー・設定キー リファレンス

> **注記**: 本エミュレータには、PB-1000版にあったような「BASICプログラムからCALLでサブルーチンをフックする」拡張機構はありません。MSXエミュレータの拡張・カスタマイズポイントは、実行時メニュー（GUI+F7）・ホットキー・`msx.ini` 設定ファイルの3つに集約されています。本ドキュメントはこれらの詳細リファレンスです。プログラム的な拡張（新しいAPIやマッパーの追加）については `dev_guide.md` を参照してください。

---

## 1. 実行時メニュー（GUI+F7）

USBキーボードで **左右いずれかの GUI キー（Windowsキー/Commandキー）+ F7** を同時押しすると、ゲームプレイを一時停止してオンスクリーンメニューが開きます（`mp/msx_menu.py` の `show_emulator_menu()` — 実体は `mp/msx_runtime_menu.py` の `show()`。GUI+F7を初めて押した時点で遅延importされる）。

操作: **↑/↓** で項目移動、**ENTER** で選択、**ESC** でメニューを閉じてゲームプレイに戻る。

| メニュー項目 | 動作 |
| :--- | :--- |
| **Swap Cartridge** | （`cart`モード時）SDカード上の `.ROM` ファイル一覧（サブフォルダ含む、現在のカートリッジのフォルダから開く）から選択し、現在のカートリッジと差し替える（自動的に `msx.reset()` される）。32KB超のROMは自動的にメガロム（ページング）方式でロードされる |
| **Swap Disk** | （`mode=disk`時）SDカード上の `.DSK` ファイル一覧から選択し、マウント中のディスクイメージと差し替える。DSKCHGフック（`mp/msx_fdd.py`）によりMSX-DOS/Disk BASIC側が自動的に認識するため、**リセットは行わない** |
| **Switch to Disk Mode** | （`cart`モード時のみ表示）Disk ROMを選択（`diskrom=`が`msx.ini`に設定済みならそれを再利用、未設定なら`.ROM`選択メニューが表示される）→確認画面（ENTER:実行/ESC:取消）→`msx.ini`に`mode=disk`と`diskrom=`を書き込んでから**MCU自体を再起動**する。ディスクイメージ自体はマウントされないため、起動後は「Swap Disk」またはmsx.iniの`disk=`でイメージを選ぶ |
| **Switch to Cart Mode** | （`mode=disk`時のみ表示）カートリッジROMを選択→確認画面→`msx.ini`に`cart=`（と`mode=`のクリア）を書き込んでから**MCU自体を再起動**する |
| **Save State** | 現在のCPU/VDP/RAM/VRAM状態をSDカードへ保存する（約2秒程度かかるため「Saving…」表示が出る）。カートリッジごとにROM本体の隣へ、最大10世代までローテーションしながら保存される（例: `ANTADV.ROM` → `ANTADV.0.sav`、`ANTADV.1.sav`、…） |
| **Load State** | 保存済みの世代一覧から選んで状態を復元する |
| **Audio Settings** | 音量・オーディオフィルタをリアルタイム調整するサブ画面を開く（下記参照） |
| **Display Settings** | LCD/HDMIの表示先切替・フレームスキップ・LCDパネル種別・回転・HDMIボーレートを調整するサブ画面を開く（下記参照） |
| **Reset MSX** | Z80をリセットする（カートリッジは変更しない） |
| **Resume** | メニューを閉じてゲームプレイに戻る（ESCと同じ） |

### Audio Settings サブ画面

| 操作 | 動作 |
| :--- | :--- |
| ↑/↓ | Volume / Filter の項目切替 |
| ←/→ | 選択中項目の値を調整（16刻み、即座に音へ反映される） |
| ENTER | 現在の Volume/Filter 値を `msx.ini` に書き込んで保存し、画面を閉じる |
| ESC | 保存せずに画面を閉じる（値自体は現在のセッション中は変更されたまま維持される） |

Volume は 0〜256（16刻み）、Filter は 0〜8（1刻み）の範囲で調整可能。

### Display Settings サブ画面

LCDとHDMIは排他表示（同時出力はできない）。項目は上から: `Display`（`LCD`/`HDMI`切替、即座に反映）、`Frame Skip`（HDMI送信の間引き、即座に反映）、`LCD Panel`（パネル機種、再起動後に反映）、`Rotate`（0/180、再起動後に反映）、`HDMI Baud`（再起動後に反映）、`Reinit <LCD/HDMI> now`（現在使用中の側をその場で再初期化 — メニューを開かず同じことができる **GUI+ESC** ホットキーもある）。

| 操作 | 動作 |
| :--- | :--- |
| ↑/↓ | 項目切替 |
| ←/→ | 選択中項目の値を調整（`Display`/`Frame Skip`は即座に反映） |
| ENTER | `Reinit ... now`にカーソルがある場合はその場で再初期化を実行（画面は閉じない）。それ以外の項目にカーソルがある場合は現在の値を`msx.ini`に書き込んで保存し、画面を閉じる |
| ESC | 保存せずに画面を閉じる |

## 2. ホットキー（ゲームプレイ中）

| キー | 動作 |
| :--- | :--- |
| **GUI + F7** | 実行時メニューを開く（上記） |
| **GUI + P** | LCD/HDMI表示をその場で切り替え（メニューを開かない） |
| **GUI + ESC** | 現在使用中の表示（LCD/HDMI）を再初期化（メニューを開かない。HDMIの長時間プレイ後のNo Signal復旧用） |

いずれもエッジトリガー（物理的に一度押すごとに1回だけ発火）で実装されているため、押しっぱなしにしても連続実行されません。

セーブ/ロードは実行時メニューの `Save State` / `Load State` から行います（2026-09-08: 単体のF5/F8ホットキーは廃止しました — セーブ/ロード時にMSX本体にもF5/F8キー入力がそのまま転送されてしまい、F5/F8を使うMSXソフトと衝突しうるため）。

## 3. `msx.ini` 完全リファレンス

SDカードの **ルート直下**（`/sd/msx.ini`）に `キー=値` 形式（`#` で始まる行はコメント）で記述します。

```ini
bios=/sd/msx/MSX_jp.rom
cart=/sd/msx/CART.ROM
lcd=ILI9341
rotate=180
volume=128
audio_filter=2
display=hdmi
hdmi_frame_skip=2
hdmi_baud=8000000
```

| キー | 既定値 | 説明 |
| :--- | :--- | :--- |
| `bios` | `/sd/msx/MSX.ROM` | BIOS/BASIC ROMファイルのパス |
| `cart` | （なし） | カートリッジROMのパス。省略時は起動時に対話式選択メニューが表示される |
| `lcd` | `ST7796` | 接続しているLCDパネル種別。`ST7796`（480×320）または `ILI9341`（320×240）。再起動が必要 |
| `rotate` | `0` | `180` を指定すると画面を上下反転表示する（LCDのみ、HDMI出力には影響しない）。再起動が必要 |
| `volume` | `256` | 起動時の音量（0-256）。実行時メニューの Audio Settings からも調整可能 |
| `audio_filter` | `0` | 起動時のオーディオローパスフィルタ強度（0-8） |
| `display` | `lcd` | `lcd` または `hdmi`。**排他**（同時出力不可） — 起動時は指定した側のハードウェアのみ初期化される。実行時メニューの Display Settings（またはGUI+Pホットキー）からライブ切替も可能 |
| `hdmi_frame_skip` | `2` | HDMIブリッジ出力を何フレームごとに送るか（`display=hdmi`の時のみ意味を持つ）。`1`で毎フレーム送信 |
| `hdmi_baud` | `8000000` | HDMIブリッジ出力のSPIボーレート（Hz）。実機検証済みなのは5MHz/8MHz — 10MHzは受信パレットが化けることが判明している。再起動が必要 |
| `hdmi_scale` | `1` | HDMI受信側でのアップスケール倍率（`display=hdmi`の時のみ意味を持つ）。`2`で512×384（受信側640×480に収まる最大値）。実行時メニューのDisplay Settingsからライブ調整可能 |
| `mode` | （なし） | `disk` を指定すると仮想FDD（フロッピーディスクドライブ）モードになる。`cart` とは併用不可（`mode=disk` の時は `cart` は無視される） |
| `diskrom` | （なし） | `mode=disk` の時に必須。カートリッジスロット1にロードするDisk ROMのパス（著作権の都合上、同梱不可 — お手持ちのDisk ROMを吸い出して配置する） |
| `disk` | （なし） | 起動時にマウントする `.DSK` イメージ（360KB/720KB）のパス。省略時、またはファイルが見つからない場合はSDカード上の `.DSK` ファイル一覧から選ぶ対話式メニューが表示される |
| `fdc_base` | `0x7FB8` | Disk ROMのFDC（WD1793/WD2793互換）レジスタがマップされているZ80アドレス（10進数または`0x`付き16進数）。多くのDisk ROMでこの既定値が使えるが、別のDisk ROMでは異なる場合がある |
| `scc` | `on` | `off` を指定すると、エミュレータ内蔵のSCC音源を無効にする（KONAMI SCCカートリッジのSCCの音が鳴らなくなる） |
| `scc_volume` | `256` | 内蔵SCCの音量（0-1024）。256でPSGと1:1 |
| `psg_volume` | `256` | PSGの音量（0-1024）。256で従来どおり、`0`でミュート（SCCだけを聴きたいとき等） |
| `fm` | `on` | `off` を指定すると、内蔵のFM音源（YM2413、MSX-MUSIC）を無効にする |
| `fm_volume` | `256` | FM音源の音量（0-1024） |
| `fm_rom` | （なし） | FM-BIOSのパス。FM-PACのイメージ（`fmpac.rom`、先頭16KBだけを使う）または16KBのMSX-MUSIC ROMをカートスロット2に置く（Cヒープを16KB使う）。後述「4.2 FM音源」 |
| `fm_id` | `off` | `on` にすると、空のスロット2が `"APRLOPLL"` のIDだけを返す（BIOSは無い）。FM-BIOSを呼ぶソフト（R-Type等）は止まるため既定はoff |
| `ext` | （なし） | `off` を指定すると `/sd/msx/ext/` と `/ext/` の拡張モジュール読み込みをスキップする。拡張を1つも使わない`cart`モードのセッションでサブルーチンフック機構自体のわずかなオーバーヘッド（後述）を完全に避けたい場合に指定する。`mode=disk`のDSKCHGフック（FDDのディスク差し替え検出に必須）はこの設定の影響を受けない |

`mode=disk` は実行時メニューで「Swap Cartridge」の代わりに「Swap Disk」が表示され、`.DSK` イメージのホットスワップができる（`mp/msx_fdd.py`のDSKCHGフックにより、MSX-DOS/Disk BASIC側が自動的に新しいディスクを認識する。リセットは不要）。Disk BASICのSAVE/LOAD、および完全なMSX-DOS起動（MSXDOS.SYS/COMMAND.COMのロード、両面アクセス）を実機で確認済み。単一ドライブ・標準3.5インチDD（360KB/720KB）ジオメトリのみ対応。

`cart` を省略、あるいは指定したファイルが見つからない場合は SD カード上の `.ROM` ファイル一覧（サブフォルダ含む）から選ぶ対話式メニューが表示されます（USBキーボード未接続時は自動的に最初の1件が選択されます）。

`volume`/`audio_filter`/`display`/`hdmi_frame_skip`/`hdmi_scale` は実行時メニューで調整して ENTER を押すと、該当キーが自動的に更新されます（他のキー・コメント行は保持されます）。`lcd`/`rotate`/`hdmi_baud`は再起動が必要なため、実行時メニューのDisplay Settingsで変更してENTERを押しても、その場では反映されず`msx.ini`に書き込まれるだけです。

かつて存在した `hdmi`（HDMI On/Off個別設定）・`boot_exclusive` の各キー、および `display=both`（同時出力）は、LCD/HDMIを完全排他にした際に廃止されました。既存の `msx.ini` にこれらの記述が残っていても無視されるだけで害はありませんが、`display=both` は `lcd` にフォールバックされます。

## 4. メガロム（バンク切替カートリッジ）対応の詳細

128KB以上のバンク切替カートリッジ（いわゆるメガロム）は、SDカードから直接ではなく、**Pico2内蔵フラッシュに一度コピーしてから**プレイ時に読み込まれます（`src/modmsx_ui.c` の `load_cart_smart()`）。

- 対応マッパー: ASCII-8 / ASCII-16 / KONAMI / KONAMI SCC / R-Type / FM-PAC。ROMの内容から自動判定される（R-TypeはXIP方式で読み込むときのみ。FM-PACは0x18の `"PAC2OPLL"` で判定）。
- **XIP方式（Pico 2、2026-11-10〜）**: ファームウェアの末尾とファイルシステムの間にある空き領域（約0.5MB）にROMを書き込み、Z80がフラッシュ上のROMを直接読む。バンク切替は読み出し先の付け替えだけで済み、RAMも使わないため、バンク切替が多いゲームでも通常のカートリッジと同じ速度で動く（実機: NEMESIS2.ROM が約28〜53FPS → 59.8FPSで一定）。
  - 初回選択時のみ、SDカードからフラッシュへ数秒かけてコピーされる（シリアルに `XIP: copying ...` と表示）。同じROMを再度選択した場合はコピーをスキップする。
  - 1本分のみ保持され、別のメガロムに切り替えると上書きされる。ファームウェアを書き換えて大きさが変わった場合も、安全のため次回ロード時に書き直す。
  - 空き領域に入らない大きなROM、およびPiZeroでは、従来のページキャッシュ方式（下記）になる。
- **ページキャッシュ方式（従来）**: ROMを内蔵フラッシュのファイル（`/megarom_cache.rom`）にコピーし、表示中の4つの8KB窓だけをRAMに置く。窓に無いページへ切り替えるたびに8KBを読み直すため、バンク切替が多いゲームでは遅くなる。
- いずれの方式でも、プレイ中にSDカードへは一切アクセスしない（LCDとSDカードが共有するSPIバスの競合を避けるため）。

**技術的背景**: 当初はバンク切替のたびにSDカードへ直接アクセスする設計だったが、①SDカードのプロトコルオーバーヘッド（1回あたり数ms〜十数ms）によりバンク切替が頻繁なゲームでFPSが実測6程度まで低下し、②LCD描画のDMA転送と同じSPIバスを取り合ってI/Oエラーを起こす、という2つの問題があった。Pico2内蔵フラッシュ（QSPI、SPI1とは独立したバス）にキャッシュする方式に変更したことで両方を解決し、通常のカートリッジと同等のFPS（52〜64程度）を達成している。

### 4.1 SCC音源

KONAMI SCCマッパーのカートリッジ（グラディウス2等）では、SCC（K051649）の音をエミュレータ内で合成し、PSGと同じPWM音声出力に混ぜて鳴らします（`msx.ini` の `scc=` / `scc_volume=` / `psg_volume=`）。

- 0x9000側のバンク番号の下位6bitが `0x3F` のとき、0x9800〜0x9FFF にSCCのレジスタが現れる（実機と同じ）。波形RAMは読み出せる（SCCの有無を確認するソフト向け）。
- セーブステートにSCCの状態も含まれる（2026-11-09以前のセーブも読める。その場合SCCは無音から始まる）。
- 変形レジスタ（0x98E0〜）とSCC+（SNATCHER等のサウンドカートリッジ）には未対応。

### 4.2 FM音源（YM2413、MSX-MUSIC）

YM2413をエミュレータ内で合成し（emu2413）、PSG・SCCと同じPWM音声出力に混ぜて鳴らします（`msx.ini` の `fm=` / `fm_volume=`）。ポート0x7C/0x7D、およびFM-PACのメモリ上の0x7FF4/0x7FF5への書き込みで鳴ります。Pico 2ではcore1で合成するため、core0の負荷はほとんど増えません。

多くのソフトは、MSX-MUSICがあると判定したときだけFMで演奏します。判定させるには次のどちらかが必要です。

- **`fm_rom=/sd/msx/fmpac.rom`（推奨）**: FM-BIOSをスロット2に置く。FM-BIOSを呼ぶソフト（R-Type等）もFMで鳴る。
- **`fm_id=on`**: 空のスロット2がIDだけを返す。ポートに直接書くソフト向けで、BIOSを呼ぶソフトは止まる。

どちらも設定しなければ、ソフトはMSX-MUSICが無いものとしてPSG/SCCで演奏します。

**FM-PACのカートリッジ**: FM-PACのイメージ（64KB）をカートリッジとして選ぶと、BASICの `_FMPAC` でFM-PACのメニューが起動します。8KBのSRAMはRAM上にのみあり、SDカードへの保存にはまだ対応していません。

- セーブステートにFM音源のレジスタも含まれる（2026-11-12以前のセーブも読める。その場合FMは無音から始まる）。
- 外部SCC基板への出力（`scc_out=`）は2026-11-12に削除しました。

## 5. ジョイスティック対応

`hardware_guide.md` の配線に従って接続すると、実機のMSXと同じ経路（PSGのI/Oポート、レジスタ14/15）でジョイスティック入力が反映されます。実機用ゲームソフトのジョイスティック読み取りルーチンがそのまま動作するため、ソフトウェア側の追加設定は不要です。GPIO配線が無い場合は常に「未入力」として扱われるため、キーボードのみでのプレイにも問題ありません。
