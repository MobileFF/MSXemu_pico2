# PWMオーディオ出力バッファ回路(A案)

GP14のPWMオーディオ出力([hardware_guide.md](hardware_guide.md)参照)を、既存のブザー直結構成のままファームウェアを変更せずに改善するための追加回路。3段RCローパスフィルタとオペアンプのユニティゲインバッファを組み合わせ、3.5mmジャック経由でヘッドホンや外部スピーカー(パワードスピーカー/アンプのライン入力)に接続できるようにする。

## 背景・課題

現行構成はGP14のPWM出力(10bit・約234kHz搬送波・22050Hzサンプル更新)をパッシブブザーに直結しており、搬送波のノイズが乗った硬い音質になっている。`hardware_guide.md`に記載の簡易RCフィルタ案(R1=R2=1kΩ, C1=C1b=4.7nF, C2=10µF)も、出力インピーダンスが約2kΩと高く、圧電イヤホンのような高インピーダンス負荷にしか向かない。一般的な16〜32Ωのヘッドホンや、入力インピーダンスがそれほど高くない機器を繋ぐと、低音不足・音量不足になりやすい。

この課題に対し、フィルタの後段にオペアンプによるユニティゲインバッファを追加し、出力インピーダンスを下げる。

## 回路構成

```
[GP14 PWM出力]
      │
     R1 1kΩ ──┬── C1 4.7nF ── GND        1段目 (fc ≈ 34kHz)
      │
     R2 4.7kΩ ─┬── C2 1nF ── GND         2段目 (fc ≈ 34kHz、段間負荷を抑えるため高インピーダンス化)
      │
     R3 22kΩ ──┬── C3 220pF ── GND       3段目 (fc ≈ 33kHz、さらに高インピーダンス化)
      │
      └── U1A(MCP6022) 非反転入力 (pin3)

  U1A: ユニティゲインバッファ構成
      pin1(出力) ── pin2(反転入力) に直結(フィードバック)

      │ pin1 出力
      ▼
     C4 10µF ── DCブロック
      │
      ├── R4 220Ω ── TIP  ─┐
      │                     ├─ 3.5mmジャック(TRS)
      └── R5 220Ω ── RING ─┘

     SLEEVE ── GND
```

R1→R2→R3を1kΩ→4.7kΩ→22kΩと段階的に大きくすることで、段間にバッファを挟まなくても各段の負荷の影響を抑え、近似的に3次ローパスフィルタとして機能させている。この比率(概ね1:4.7:22)を保てば、定数自体を多少前後させても構わない。

### 電源・バイアス

- U1 pin8 (V+) → Pico の `3V3` ピン
- U1 pin4 (V−) → GND
- C5 (100nF) を V+–GND 間、U1のできるだけ近くに配置しパスコンとする
- PWM無音時のデューティ比は約50%のため、フィルタ後の直流バイアスは自然に約1.65V(Vcc/2)付近になる。MCP6022はレールtoレールなのでこの中点バイアスのままバッファできる

### 未使用チャンネル(U1B)の処理

MCP6022はデュアルオペアンプだが、本回路で使うのは片側(U1A)のみ。もう片方(U1B)は入力をフローティングのまま放置すると発振や消費電流増大の原因になるため、以下のように処理する。

- pin5 (IN+ B) → GND
- pin6 (IN− B) ⇄ pin7 (OUT B) を直結(ボルテージフォロワ化)
- pin7 (OUT B) はどこにも接続しない(未使用)

## オペアンプ(U1)の選定

単電源3.3V動作・レールtoレール入出力(RRIO)・標準的なデュアルop-amp用DIP-8ピン配置(1:OUT A, 2:IN-A, 3:IN+A, 4:V-, 5:IN+B, 6:IN-B, 7:OUT B, 8:V+)であることを条件に検討した。

| 型番 | 判定 | 理由 |
|---|---|---|
| **MCP6022** | ◎ 採用 | 1.8〜6V単電源、RRIO。3.3V駆動にそのまま使える |
| AD8506 | ◎ 電気的には最良 | 1.8〜5V単電源・RRIO・低消費電力。ただしパッケージが8-lead MSOP(表面実装)でブレッドボード直挿し不可 |
| TLC2272 | △ 非推奨 | 保証された単電源動作は4.4V〜。3.3Vは規格外 |
| LMC660CN | × 不可 | 単電源5V〜15.5Vが規格。3.3Vは動作保証外、パッケージもDIP14(クワッド)で別物 |
| NJM4580DD / NJM4558S | × 不可 | いずれも規格が±2V〜(単電源換算で最低4V〜)。3.3Vは規格外、パッケージもSSOP/SOP(表面実装) |
| NJM4556S | × 不可 | 高出力電流タイプだが規格は±2V〜(実用的には±9V程度で使われる)。3.3Vでは規格外かつ本来の性能を発揮できない |
| LM311P | × 使用不可 | そもそもオペアンプではなくコンパレータ(電圧比較器)。出力がオープンコレクタでリニアなバッファ動作ができない |

## 案B(参考): I2S DAC化との比較

本回路はPWM+アナログフィルタ構成のままファームウェア変更なしで音質を改善する方式(A案)。より根本的に音質を上げたい場合は、GP14のPWM出力をやめてPCM5102Aなどの安価なI2S DACモジュールに置き換える方式(案B)がある。既存の`audio_ring_buf`(22050Hz PCMサンプル)をI2S用のPIO/DMA転送に差し替える形でファームウェア側の実装が必要になるが、PWM搬送波ノイズが原理的に発生しなくなり、ヘッドホン・ライン出力どちらにも直結できる。まずは本ドキュメントのA案で改善を図り、必要に応じて案Bへ移行する想定。
