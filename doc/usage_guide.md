# 利用ガイド

## 1. 初期設定

### 必要なもの

- ビルド済みファームウェア（`firmware/firmware_msx.uf2`。`build_guide.md` 参照）を書き込んだ Raspberry Pi Pico 2
- MSX BIOS/BASIC ROM（32KB）— 著作権の都合上このプロジェクトには含まれません。各自でご用意ください
- （任意）カートリッジROM
- microSDカード（FAT32でフォーマット）
- USBキーボード + USB OTGアダプタ

### SDカードのディレクトリ構造

```
/sd/msx/
  MSX_jp.rom       # BIOS ROM（ファイル名は任意、config.txtで指定）
  ANTADV.ROM       # カートリッジROM（任意、複数可）
  NEMESIS.ROM       # 大容量（メガロム）カートリッジも同じ場所に置いてよい
  config.txt        # 設定ファイル（任意、無くても動作する）
  save.bin          # セーブステート（自動生成、初回セーブ時に作成される）
```

### `config.txt` の書き方

```ini
bios=/sd/msx/MSX_jp.rom
cart=/sd/msx/ANTADV.ROM
lcd=ST7796
rotate=0
volume=256
audio_filter=0
```

全キー省略可能。省略時のデフォルトや各キーの詳細は `ext_hooks_guide.md` の「`config.txt` 完全リファレンス」を参照してください。`cart` を省略すると、起動時にSDカード上のROM一覧から選ぶメニューが表示されます。

---

## 2. 起動フロー

1. Pico 2 に電源を投入（USB接続）すると MicroPython が起動する
2. （開発運用時）`mpremote` 等で接続し `import main; main.run()` を実行する
3. 以下の順で自動的に初期化される:
   - クロック調整・UARTコンソール準備
   - USBホスト初期化（キーボード検出開始）
   - SDカードマウント
   - `config.txt` 読み込み
   - LCD初期化（パネル種別・回転設定を反映）
   - BIOS ROM ロード
   - カートリッジロード（`config.txt` 指定 → 対話式選択 → 未選択ならMSX BASIC起動）
   - オーディオセットアップ
4. MSXが起動し、BASICプロンプトまたはカートリッジのゲームが開始される

起動時の画面には現在のFPS・オーディオリングバッファ残量が300フレームごとにコンソールへ出力されます（実機のシリアルコンソールで確認可能）。

---

## 3. キーボード操作

USB キーボードは HID レポートを直接 MSX のキーボード行列にマッピングします。物理的なキー配置は実機のMSXキーボードにできるだけ近づけていますが、**どの文字がどのキーに割り当たるかは使用しているBIOS ROMの地域仕様（日本語版/英語版）に依存**します。例えば英語版BIOSではShift+;で`:`が入力されますが、これはUS配列のBIOS側の仕様であり、キーマッピング自体は物理キー位置ベースで一貫しています。

### 特殊キー・ホットキー

| キー | 動作 |
| :--- | :--- |
| F5 | クイックセーブ |
| F8 | クイックロード |
| GUI（Win/Cmd）+ F7 | 実行時メニューを開く |

詳細は `ext_hooks_guide.md` を参照。

---

## 4. ジョイスティック

`hardware_guide.md` の配線に従ってGPIOに接続すると、実機と同じ方式（PSG経由）で認識されます。ソフトウェア側の追加設定は不要で、実機用ゲームソフトのジョイスティック読み取りルーチンがそのまま動作します。配線が無い場合は常に「未入力」扱いとなり、キーボードのみでプレイできます。

---

## 5. 実行時メニュー（GUI+F7）

ゲームプレイ中に **GUIキー+F7** を押すと、以下の操作ができるメニューが開きます:

- **Swap Cartridge** — 別のカートリッジに差し替える（メガロムも選択可能）
- **Save State** / **Load State** — 現在の状態をSDカードに保存/復元する
- **Audio Settings** — 音量・音質をリアルタイム調整する
- **Reset MSX** — Z80をリセットする
- **Resume** — ゲームプレイに戻る

各項目の詳細な挙動は `ext_hooks_guide.md` を参照してください。

---

## 6. 大容量カートリッジ（メガロム）について

128KB以上のバンク切替カートリッジ（グラディウス/ネメシス等の一部KONAMIタイトル、その他ASCII-8/ASCII-16マッパー採用タイトル）も、通常のROMと同じようにSDカードの `/sd/msx/` に置いて `cart=` またはメニューから選択するだけでプレイできます。

初回選択時のみ、Pico2内蔵フラッシュへ数秒かけてコピーする処理が入ります（画面に「Loading…」と表示されます）。以降はそのキャッシュから高速に読み込まれ、通常のカートリッジと同等の速度でプレイできます。技術的な詳細は `ext_hooks_guide.md`・`architecture.md` を参照してください。

> 対応マッパーは ASCII-8 / ASCII-16 / KONAMI（SCC無し）です。KONAMI SCC（拡張音源チップ搭載）カートリッジは現時点で音源チップ部分が未対応です。

---

## 7. セーブステート

`F5`（保存）/ `F8`（読み込み）のホットキー、または実行時メニューの `Save State` / `Load State` から、CPU・VDP・RAM・VRAMの状態を丸ごとSDカードの `save.bin` に保存・復元できます。セーブファイルは約80KB。1スロットのみ（複数セーブスロットには非対応）。

---

## 8. トラブルシューティング

| 症状 | 対処 |
| :--- | :--- |
| 起動画面が真っ暗 | LCDとSDカードは配線を共有しているため、まず物理配線を確認（`hardware_guide.md`）。SDカードも同時に認識しない場合はほぼ配線不良 |
| キーボードが反応しない | USB OTGアダプタの接続を確認。ファームウェア側の `usb_host.start_bg_timer(8)` 呼び出し忘れが原因のこともある（開発者向け、`build_guide.md` 参照） |
| 音が割れる・耳障り | `config.txt` の `volume=` を下げる、`audio_filter=` を上げる（実行時メニューのAudio Settingsからも調整可）。根本的な改善にはハードウェアのRCフィルタ追加を推奨（`hardware_guide.md`） |
| 音程が違って聞こえる | 過去に実際にあったバグ（PSGクロック設定ミス）は修正済み。最新のファームウェアを使用しているか確認 |
| メガロムの読み込みに時間がかかる | 初回選択時のみSD→内蔵フラッシュコピーが発生するため正常（数秒程度）。2回目以降は高速 |
| セーブ/ロードでエラーになる | SDカードの空き容量・書き込み可否を確認。それでも解決しない場合はSDカードの物理的な接触不良の可能性 |
